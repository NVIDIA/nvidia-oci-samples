How This Demo Works

developer guide

1. Start With Help

Use this page first. Create a build.nvidia.com key, paste it into the API Keys tab, generate the sample receipts, then import the image folder.

2. Intake

A folder of receipt images becomes one trip report with one expense line per receipt. This public sample uses synthetically generated ABC Company receipts so the demo is self-sufficient.

3. Nemotron Parse

When a build.nvidia.com key is provided, the server sends each receipt image to Nemotron Parse using a chat-completions endpoint and requests Markdown/OCR layout evidence.

4. Nemotron Omni

Omni receives the Parse evidence and converts it into normalized expense fields, confidence scores, provenance, and display-safe rationale.

5. Agentic Repair

The agent checks for missing or weak fields, retries Parse when needed, repairs gaps such as hotel folio card-settlement totals, applies ABC Company policy, and decides whether the line is ready or blocked.

6. Human Review

Receipts might have obscured content that is hard for OCR to detect. The agent should recover visible context but stop before guessing the final amount. End users should be able to inspect hard images, correct fields, save final values, and export CSV of fixed values.

Run This Sample Locally

hands-on setup

Prerequisites

Install Git, Node.js 24 or newer, npm, and a modern browser. npm is included with Node.js. Verify setup with git --version, node --version, and npm --version.

macOS / Linux

git clone https://github.com/NVIDIA/nvidia-oci-samples.git
cd nvidia-oci-samples/generative-ai-samples/agentic-multimodal-expense-intelligence
npm run generate:receipts
npm run dev

Windows PowerShell

git clone https://github.com/NVIDIA/nvidia-oci-samples.git
cd .\nvidia-oci-samples\generative-ai-samples\agentic-multimodal-expense-intelligence
npm run generate:receipts
npm run dev

Open And Import

Open http://127.0.0.1:8790, go to API Keys, paste the build.nvidia.com key, then use the folder picker to select data/sample-receipts/images.

No Install Step

This sample has no runtime npm dependencies, so npm install is not required for the demo scripts. Running npm test is optional.

If Commands Are Missing

If git, node, or npm is not found, install Git from git-scm.com/downloads and Node.js 24 or newer from nodejs.org. npm is included with Node.js. Close and reopen the terminal so PATH updates are applied.

Get A build.nvidia.com API Key

developer setup

1. Open Build

Go to build.nvidia.com and sign in. If you don't have an account, create a new one.

2. Open Models

Use the Models page to find Nemotron Parse, Nemotron Omni, or another hosted NIM endpoint. Model pages show API examples, endpoint details, and the model id developers can call.

3. Generate Key

Go to the build.nvidia.com/models tab, search for "nemotron parse" and create an API key by clicking the "Get API Key" button. Copy the generated nvapi-... value locally; do not commit it to source control.

4. Paste In Demo

Return to this app, open the API Keys tab, paste the key under NVIDIA hosted API key, and save it for the browser session before importing receipts.

Why build.nvidia.com Matters

beyond this demo

Hosted NIM APIs

build.nvidia.com lets developers prototype against cloud-hosted NVIDIA NIM endpoints before deciding how to integrate, deploy, or scale models in their own workflow.

Model Variety

The catalog spans language and reasoning models, multimodal/image-to-text models, OCR/document models, retrieval/RAG models, code generation, speech, visual generation, safety, healthcare, weather, and physical-AI use cases.

Blueprints

Blueprints package workflows and code samples so developers can move from a model call to an application pattern such as agents, vulnerability analysis, retail workflows, or AI factory digital twins.

Developer Takeaway

This expense sample is one pattern: Parse creates evidence, Omni reasons over it, and NemoClaw-style controls govern the agent. The same idea can be reused in ERP, CRM, procurement, service, and document-heavy workflows.
